# Questions 'n Answers

## Why AI?

The OG game uses four 3D formats to store its models

- Blitz3D (.b3d) Binary file
- RoomMesh (.rmesh) Binary file
- DirectX (.x) Stored as plain text or compressed binary zip
- 4×4 Evolution Model File (.smf) Binary file

Thankfully as this game has an active modding community, there's plenty of import/export tools for Blitz3D files, but the rest I couldn't find any tools that could open them.
Not only that, as of writing I lack the experience or time to sit down, reverse engineer and implement my own extractors, so I had to use AI for this part.

Rest assured only the extractors are AI generated, and the rest of the assets here aren't made or touched by it.
Please if you have or know where I can find extractors for those files, let me know!

## Why make this?

The original runs on the Blitz3D engine, which is a fairly outdated and has a myriad of issues such as instability, graphical glitches, crashes such as the famous “Memory Access Violation” error.

Not only that, it’s stuck on Windows, which many have or plan on hopping off due to incompetent decisions from Microsoft, so having it run on Linux or even MacOS would be great.
